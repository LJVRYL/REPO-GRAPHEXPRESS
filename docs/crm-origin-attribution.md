# Native CRM attribution

The CRM reads the existing Google consent/campaign cookie only on actual submitted requests, customer registration and new web orders. It creates no anonymous CRM contacts and adds no GA/GTM emitter. Scope is GE_Organization::PRIMARY on graphex.ar. Feature flags: ge_crm_origin_enabled (default false), ge_crm_origin_active_since (UTC Unix seconds).

Metadata _ge_crm_origin_v1 on native requests/customers/quotes/Woo orders; protected origin in CRM payload. Request first receipt uses _ge_crm_origin_received_at. Schema 1 contains organization_id, first_touch, latest_touch, recorded_at, consent and explicit internal provenance. Touch fields: bucket, source, medium, campaign, content, public landing, normalized referrer_provider, captured_at, evidence, confidence. Cookies: ge_growth_consent=granted and valid ge_growth_touch (first/last, first_at/last_at, expires_at **Unix seconds**, maximum 30 days). Only safe normalized marketing identifiers and public catalogue paths are retained. No click IDs, GA client/session IDs, IPs, query strings, private URLs, form values or contact details.

Source buckets: google_maps (google / organic / graphex_maps), google_organic, paid_campaign, organic_social, referral, direct_unknown. UTM/referrer is a browser indicator, never proof of an individual identity. Optional consented referrer_host recognizes a bounded provider allowlist. The current Google capture contract provides UTM but no referrer_host: untagged organic traffic remains unknown until its capture is extended by the Google owner. Do not infer acquisition from the AJAX HTTP Referer, raw mail text, names or transport channel. No verified email/WhatsApp campaign marker adapter is implemented in this release.

First customer source stays unchanged, including unknown for pre-existing customers. Later real observations update latest source. Each work preserves source from its explicit request -> quote -> primary order link. Unrelated customer history and the operator's browser never supply work attribution. An empty factory order waits for quote linkage or a populated web order before attribution; its provisional save must not replace the original quote source. Manual lead conversion can carry an already recorded source to its actual selected customer. Cross-brand and mismatched customer links are rejected. Old objects are not assigned a guessed source.

CRM /gestion/?section=crm&view=origin reads native scoped records. Dates use America/Argentina/Buenos_Aires with an exclusive next-day endpoint and maximum 366 calendar days. Each stage is an event count in the selected period, not a cohort conversion rate. Submitted requests and distinct commercial conversations are inquiries; drafts, historical mail backfill, machine mail and delivery failures are excluded. Historical requests without receipt timestamps use creation date. New customers use registration date; each quote is counted once, regardless of versions. Only primary Woo orders count, excluding payment/work helper orders.

Paid sales require full financial evidence and date_paid in the period: reconciled exact credited-attempt ledger for commercial orders, audited native manual confirmation, or a paid order with transaction ID. Credit approval and a partial deposit are not fully paid sales. A cancellation status alone does not erase an already credited commercial ledger or audited manual receipt: dated refunds determine the net amount. Repeated payment keys are deduplicated; conflicting keys are rejected. Amount includes tax/shipping, less dated refunds through period end, with exact integer cents and separate currencies. This is a paid-order cohort, not a complete bank cash-flow ledger or GA revenue definition.

Integration preserves the deployed ge_crm_thread_agent UI hook. Attention classifier, receipt policy, mail transport and immutable source-message hash remain unchanged. Existing Meta channel adapters stay in place. Google owns measurement.js and its capture contract; CRM owns class-ge-crm-origin.php and the two small loader/UI integrations. New future marker contracts must be independently validated before trusted native consumption.

QA: tests/crm-origin-wp.php refuses production, uses disposable native fixtures in graph_job_flow_20261007 and mail/HTTP sinks. Verify PHP 7.4/8.1 plus CRM attention and payment-policy regression. Deployment exports exact Git bytes, guards live source hashes, backs up code and feature options privately, drills restoration before publication, then performs read-only production checks. Rollback disables this capture and restores guarded loader/UI originals while retaining genuine contacts, messages and origin metadata; the helper can remain inert. Never copy private CRM message payloads into QA.
