# Despliegue de Graphex para workers

Producción de `graphex.ar` usa el broker firmado `/usr/local/sbin/graphex-code-broker` en el VPS `vps-6443807-x`. Se puede ejecutar desde la terminal autenticada de Coolify de ese VPS. Este flujo usa la sesión y la identidad de firma existentes del operador.

1. Seguí [la política de releases](GRAPHEX_RELEASE_POLICY.md). Prepará y probá el cambio en una rama aislada. Verificá la integración en `master` y guardá el SHA canónico de 40 caracteres. Incluí una prueba del flujo HTTP real para los cambios de carrito, checkout o pagos.
2. En la terminal de Coolify confirmá el host con `hostname -f`. Hacé una consulta de solo lectura al broker con `op: inspect` y `paths` con los archivos exactos. La respuesta incluye código en base64. Para reportar la inspección, conservá solo estado, rutas y hashes.
3. Armá el manifiesto con `version: 1`, `operation: deploy`, `project: graph-express`, `resource: donweb-cloud-6443807`, `incremental_publish_safe: true`, `local_commit`, `task_ref`, `authorization_ref` y `files`. Cada archivo lleva `path`, `before_sha256` de la inspección y `after_sha256` de Git. Un archivo nuevo usa `null` en `before_sha256` y requiere una carpeta permitida que ya exista. Si Git y el servidor difieren del punto de partida esperado, explicá la diferencia antes de publicar.
4. En la máquina del operador, con Python, OpenSSH y la identidad de firma de Graphex disponibles, ejecutá `python ops/graphex-signed-release.py ruta-al-manifiesto.json`. El comando imprime un bloque para Coolify. Ese bloque verifica la línea de base, descarga los archivos del commit canónico, comprueba su SHA-256, usa el broker y vuelve a leer los hashes. La clave de firma permanece en la máquina del operador.
5. Ejecutá el bloque generado en la terminal ya autenticada. Al recibir `COMMITTED` con respaldo y hashes verificados, probá el flujo real del cambio. Guardá el estado de la prueba y el commit en el Result Pack. Si se perdió la sesión, inspeccioná los hashes antes de reintentar. Si falta acceso, pedí al operador existente que abra la terminal y complete el despliegue desde el mismo manifiesto.

Los destinos permitidos se resuelven en el broker. El caso de Envíos se integró en el plugin principal de Graphex para usar la ruta ya permitida. El código publicado en este caso proviene del [PR 78](https://github.com/LJVRYL/REPO-GRAPHEXPRESS/pull/78) y sus correcciones en `master`.
