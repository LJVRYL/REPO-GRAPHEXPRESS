# Per-product template access

Every mapped catalog item advertises its available template through a stable, cache-safe download gate. Unauthenticated visitors reach the existing Graphex registration form. Successful registration or portal login returns to the originating item using a one-hour signed, HttpOnly/SameSite context; failed or unrelated authentication does not redirect. No authentication or account-creation implementation is replaced.

A registered visitor receives the PDF directly only when all options share one exact reference. Multiple measures or held/missing options lead to the existing product selector. Products without a valid published reference show availability/request text rather than a false download. The central authenticated/nonce-protected PDF delivery route remains unchanged. The combined library is unchanged.

Validation: exact option mapping, guest/member cards, registration and selection redirects, malformed item input, signed return expiry/tampering and one-time consumption, plus the existing PDF-integrity and organization-policy fixtures. No real account registration, customer data or commercial mutation is used for testing.
