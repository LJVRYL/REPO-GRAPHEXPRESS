# Windbanners: consistent separate choices

All 25 active families keep their 164 native option keys, prices, quantities, images and template mappings. The previous net + IVA policy is unchanged.

Fly banners use Altura (or Tamaño for Oval), followed by Impresión: Simple faz / Doble faz. Gazebos retain Estructura, Medida and Paredes. Wall banners separate model, measure and printing. Puffs separate model, applicable size and filling. Cintas separate product, hardware and width. Backdrops show width × height in cm based on their existing descriptions (208 cm height). Mostradores use Forma; tótems separate model and shape.

Bases and stakes separate type, stake length and counterweight. Only the applicable controls are visible: choosing a stake shows length; choosing a cross base shows counterweight. The existing source specifies an empty counterweight case, so its choice explicitly says “Con estuche de sobrepeso”. Optional dimensions use an internal `__none__` marker which is never presented as a customer choice. Dependent controls keep the exact native purchase key synchronized with prices, minimum quantities, templates and gallery filtering.

Presentation repairs the known misencoded accented characters without rewriting the native source records or historical orders. No new product combinations or options are fabricated. Regression covers all native choices, optional field visibility, purchase totals and gallery events. Production changes are limited to four code files with precondition hashes, verified broker backup and selective rollback; the result pack records the final canonical commit and live verification.
